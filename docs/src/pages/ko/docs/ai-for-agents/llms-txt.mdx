# AI 통합

overlay-kit은 ChatGPT, Claude, Cursor 같은 AI 에이전트가 라이브러리 문서를 읽고 실제 API를 근거로 답할 수 있도록 몇 가지 자료를 제공하고 있어요.

## llms.txt

overlay-kit은 [llms.txt](https://llmstxt.org/) 파일을 제공하고 있어요. llms.txt는 AI 어시스턴트와 대규모 언어 모델(LLM)이 프로젝트 문서를 더 효과적으로 이해할 수 있도록 돕는 표준이에요.

### `/llms.txt`

overlay-kit 문서의 구조화된 목차로, 개별 페이지로의 링크를 포함하고 있어요. AI 도구가 특정 가이드나 API를 찾아볼 때 유용해요.

- **URL**: [https://overlay-kit.slash.page/llms.txt](https://overlay-kit.slash.page/llms.txt)

### `/llms-full.txt`

영문 문서 전체를 하나의 파일로 합친 것이에요. AI 도구에 overlay-kit에 대한 포괄적인 컨텍스트를 제공하고 싶을 때 유용해요.

- **URL**: [https://overlay-kit.slash.page/llms-full.txt](https://overlay-kit.slash.page/llms-full.txt)

### `/ai.txt`

overlay-kit의 공식 API에 대한 신뢰도 높은 사실을 짧게 정리한 파일이에요. 어시스턴트가 존재하지 않는 메서드를 만들어내지 않도록 잡아주는 용도예요.

- **URL**: [https://overlay-kit.slash.page/ai.txt](https://overlay-kit.slash.page/ai.txt)

### AI 도구에서 활용하기

많은 AI 도구와 LLM 기반 애플리케이션이 llms.txt 표준을 지원하고 있어요. 이 엔드포인트를 사용하면 AI 어시스턴트에게 overlay-kit의 API와 기능에 대한 전체 컨텍스트를 제공할 수 있어요.

예를 들어, AI 코딩 어시스턴트에게 URL을 전달하면 코드를 작성할 때 overlay-kit 문서를 참고할 수 있어요.

    오버레이 관리는 overlay-kit을 사용해 주세요. 문서: https://overlay-kit.slash.page/llms-full.txt

## 마크다운 복사

문서 전체가 아니라 한 페이지만 어시스턴트에게 전달하고 싶다면, `/docs`와 `/api` 아래의 모든 페이지에는 우측 상단에 **마크다운 복사** 버튼이 있어요.

- 왼쪽 라벨을 클릭하면 현재 페이지의 원본 MDX가 클립보드에 복사돼요.
- 화살표를 클릭하면 현재 페이지를 **ChatGPT**나 **Claude**에 미리 입력된 상태로 열어요. 입력되는 prompt는 이렇게 생겼어요.

```
Read <page-url>, I want to ask questions about it.
```
